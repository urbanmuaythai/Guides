Tasks guideUrban Muaythai workflowPrepared 18 October 2026 · Brisbane time

When to use a task

Create one as soon as a member or prospect needs an action that cannot be finished now, or another staff member needs to take over.

Member & prospect work

Booked calls, missing onboarding items, attendance conversations, rollover checks and member enquiries.

Keep the next step visible

Record who will do what and when. A profile note stores the history; a task makes the next action visible.

Check before creating. Read existing Tasks, Notes and Comms. Update an existing task for the same action rather than creating another reminder or duplicating member contact.
01

Review your tasks each day

  1. Open Tasks in Clubworx. The original training guide also shows due-task alerts on the Tasks menu and Dashboard.
  2. Filter Assigned to your user, Status to unfinished work, and Due before/on today. Review overdue items as well as today’s tasks. Clear filters if an expected task is missing.
  3. Read each task and open the linked member/prospect. Check recent notes, replies, bookings, attendance or payment evidence relevant to the action.
  4. Act, record the result, or leave a specific next action with an owner and review date. Review anything waiting before the end of your shift.

Do not rely on reminder emails alone. An overdue task needs review; its age does not automatically change who owns it.

02

Create & assign a task

  1. Find the correct person first. Match the name and contact details; use the Clubworx contact ID where available. For a Book a Call prospect who is missing, use + Add → Prospect, enter verified booking details, save, and confirm the new profile.
  2. On the member/prospect profile, select Tasks → Add task. You can also use the main Tasks → Add Task page; explicitly select the correct Contact there. Recheck for an existing task before saving.
  3. Set Assigned to the person responsible for the next action. Use the ownership guide below. If the correct person cannot be selected, record the assignment issue and ask Mel to resolve access.
  4. Choose the appropriate existing Type, such as phone call, email or meeting. Use the team’s existing task types. Creating a new type is not required for this procedure.
  5. Set Due date and time to when the action must happen. For a booked call, use the confirmed appointment time. Use Australia/Brisbane and check the displayed time against the booking.
  6. Write a specific Description: action and person on the first line, then context, source, verified facts, required outcome and any missing information. Use the templates below. If your screen has no separate title field, the first description line serves as the task heading.
  7. For a task another staff member needs to see, leave Private task unticked. Check the available New Task and reminder email preferences for the intended assignee before saving. These are staff task notifications.
  8. Click Save. Reopen the task and verify its contact, assignee, type, description, due date/time and unfinished status. Confirm it appears on the correct profile and in the task list.

04

Update without losing the history

  1. Open the existing task and check the current profile record before acting. Confirm another staff member has not already completed the action.
  2. Add the latest update above the old notes. Include your initials and date; use ---- to separate it from the previous entry. Preserve the original request and earlier updates.
  3. Record what actually happened: spoke to member, no answer, voicemail left, reply received, awaiting approval, or check completed. A prepared draft is not a sent message.
  4. Use In Progress while actively working, or Waiting when a member reply, manager decision or external result is needed. Record exactly what you are waiting for, the owner and a follow-up date.
  5. If the next action or appointment changes, update the due date/time, assignee and related booking/tracker as needed. Preserve the original timing and reason in the history. Save and verify.

Failed-payment reminders: verify the invoice history, exact error and current payment state before the next action. A pending payment needs an outcome check. A completed bank-update form does not settle the debt. Keep outreach drafts unsent for Ram to review/send under the current workflow.
05

Complete the action, record what remains

Choose Done only after the task’s action or final disposition has been recorded. Add the actual completion date, staff initials, result and any supporting profile note.

A call task can be done

Sales Guy has made the call and logged the result. If there is no answer or further work is needed, save a dated follow-up before closing that attempt. Do not record the prospect as converted without a confirmed outcome.

A case may still be open

An SMS sent, form completed or review performed can finish that task action. Keep the failed-payment case open until its outcome is verified, with another task or clear next review where needed.

Keep the record. Use status and dated notes for routine completion. Do not delete an unresolved task to clear an overdue list, or mark it Done simply because a reminder was sent.
